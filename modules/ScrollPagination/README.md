# 스크롤 페이지네이션 모듈

이 모듈은 Spring Data JPA의 `ScrollPosition`과 `Window` API를 사용하여 커서 기반 페이지네이션을 구현하는 방법을 보여줍니다.

## 개요

커서 기반 페이지네이션은 결과 집합 내의 특정 항목을 가리키는 커서를 사용하여 다음 페이지의 시작 위치를 결정하는 페이지네이션 기법입니다. 이 방식은 특히 대용량 데이터셋이나 페이지 요청 사이에 항목이 추가되거나 제거될 수 있는 경우에 오프셋 기반 페이지네이션보다 더 효율적이고 안정적입니다.

## 주요 구현 요소

- **엔티티**: `Product` 클래스를 사용하여 데모를 구현
- **리포지토리**: 커서 기반 페이지네이션을 위한 메서드 정의
- **서비스**: 커서 기반 페이지네이션을 처리하는 메서드 제공
- **컨트롤러**: 커서 기반 페이지네이션을 위한 REST 엔드포인트 노출

## 사용 방법

- 제품 생성: POST 요청을 통해 제품 생성
- 페이지네이션을 통한 제품 조회: 초기 요청과 후속 요청에 커서 사용

## 커서 기반 페이지네이션의 장점

1. **성능**: 전체 항목 수를 계산할 필요가 없어 대용량 데이터셋에 더 효율적
2. **일관성**: 페이지 요청 사이에 항목이 추가되거나 제거되어도 일관된 결과 제공
3. **확장성**: 대용량 데이터셋과 고트래픽 애플리케이션에 적합
4. **단순성**: 복잡한 정렬이 필요한 오프셋 기반 페이지네이션보다 구현 및 유지 관리가 용이

## 개선 포인트

- PaginationResult 에서 nextCursor 는 서버에서 계산하지 않고 클라이언트에서 구현하게 위임방법
