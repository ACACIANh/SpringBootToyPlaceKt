# Graceful Shutdown 테스트 모듈

이 모듈은 스프링 부트 애플리케이션의 Graceful Shutdown 기능을 테스트하기 위한 모듈입니다.

## 테스트 방법

1.  **애플리케이션 실행:** 본 모듈의 스프링 부트 애플리케이션을 실행합니다.
2.  **요청 전송:** `http://localhost:8080/graceful-shutdown` 주소로 GET 요청을 보냅니다. 이 요청은 N초가 소요됩니다.
3.  **애플리케이션 중지:** 요청이 진행되는 동안 애플리케이션을 중지합니다.
4.  **동작 확인:** 애플리케이션이 즉시 종료되지 않고, 진행 중인 요청이 완료될 때까지 대기합니다. 클라이언트에서 "Graceful shutdown is working!" 응답을 확인합니다.

## 스케줄러

본 모듈에는 매초 실행되는 스케줄러가 포함되어 있습니다. 애플리케이션 종료 시, 스케줄러가 현재 작업을 마칠 때까지 대기한 후 종료됩니다.
